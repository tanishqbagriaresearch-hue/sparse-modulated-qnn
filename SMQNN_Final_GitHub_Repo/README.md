# SMQNN: Sparse Modulated Quantum Neural Networks

Mitigation of barren plateaus through modular entanglement and mid-circuit measurements.

## Quick Start

```bash
pip install -r requirements.txt
python -m pytest tests/  # Verify installation
python scripts/generate_figures.py  # Reproduce all figures
```
